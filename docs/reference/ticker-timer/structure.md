# 打点计时器结构依据

参考图保存在 `images/`（11 张），说明书/讲义在 `papers/`。

## 电磁打点计时器（J0203 / JY38-84）

主要尺寸（余姚神马 12006 说明书）：144 × 70 × 35 mm；纸带宽 17.5 mm；复写纸 Φ34 mm；阻力 ≤ 3 gf；周期 0.02 s。

| 部件 | 位置（沿纸带 +X） | 作用 |
|---|---|---|
| 接线柱 | 底座左端，红/绿两柱 | 接 4–6 V（教材）或 6–9 V（厂标）交流 |
| 线圈 | 接线柱右侧，轴线沿纸带 | 50 Hz 交变磁场，磁化振片 |
| 永久磁铁 / 极靴 | 线圈与打点针之间，上下夹振片 | 使振片每周期上下各一次，打点频率 = 电源频率 |
| 振动片 | 穿过线圈，左端固定螺丝，右端自由 | 固有频率调到 50 Hz 共振 |
| 打点针 | 振片自由端，竖直向下 | 撞击复写纸，在纸带上留点 |
| 复写纸 | 定位轴上，有色面朝下 | 在纸带上复印点迹 |
| 限位孔 | 打点区两侧门型导轨 | 约束 17.5 mm 纸带 |
| 压纸框架 / 打点垫板 | 复写纸上方 / 纸带下方 | 保证针、纸、垫板垂直接触 |

纸带顺序：**复写纸在上，纸带在下**，穿过两侧限位孔。

## 电火花打点计时器（实验室常见封闭塑料壳）

工作电压 220 V AC。拆解图显示：左侧电源盒（开关、指示灯、整流板），右侧打点头（墨粉盘 + 放电针）。

| 部件 | 位置 | 作用 |
|---|---|---|
| 电源线 / 开关 / 指示灯 | 电源盒顶面或侧面 | 220 V 供电与脉冲开关 |
| 线路板 | 电源盒内 | 正半周给电容充电，负半周触发可控硅 |
| 升压线圈 | 邻室分段绕制次级 | 初级脉冲 → 次级数万伏 |
| 墨粉纸盘 + 纸盘轴 | 打点头中部，负极 | 导电并留下墨点 |
| 放电针 | 墨粉盘下方，正极 | 击穿纸带产生火花 |
| 纸带压板 / 限位槽 | 打点头上方与两侧 | 纸带从墨粉盘**下面**穿过 |
| 脉冲输出插孔 | 打点头侧面红/黑 | 高压输出（课堂一般不用） |

竖直叠放：导电片/压板 → 墨粉盘 → 纸带 → 放电针。

电火花型号按实物为 **J01203**（不是电磁式的 J0203）。课堂摆放时电源盒在左侧、打点头朝纸带方向；盒体 +Z 面开口，便于看见升压线圈。

## 打点物理

- 两种计时器在 50 Hz 下都是 **T = 0.02 s 打一点**（交流电一个周期一次）。
- 电磁式振针接触纸带，阻力大；电火花无接触，阻力小。
- 课堂操作：先通电，再释放纸带。
