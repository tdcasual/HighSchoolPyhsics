# 电势地形与电场线场景审计

审计日期：2026-09-27
本地场景：/electrostatic-lab
参考：[Dmit 电场线与等势线 · 从电场到电势](https://dmit.20030624.xyz/field-lines.html?v=20260923-unequal)

## 结论与范围

Dmit 原页以二维画布组织“电场线、等势线、电势能”教学阶段，提供多种电荷分布、A/B 测点及电势/场强关系观察。本地场景把二维电势 φ(x,z) 映射成三维地形，另有可编辑电荷、单探针和场线。三维地形是函数图像，有助于观察正负电势的高低分布；它不是实际三维空间中的等势面。本地 UI 已明确此模型边界。

模型采用相对单位、忽略库仑常数，并用软化尺度 ε=0.24 避免点源奇点：
φ=Σqᵢ/√(rᵢ²+ε²)，E=−∇φ。
绘图高度 h=0.62×6.5×tanh(φ/6.5) 是压缩后的显示坐标，不是物理高度。场线按固定步长 0.2 追踪，适合定性演示，不作为数值场强求解器。

## 审计发现与处理

- **等势线重复段：** 对称电偶极子的零电势线恰落在采样网格列上时，邻接单元会重复提交同一线段。增加格点交点去重、短段过滤和无向线段键去重；保留原有沿网格边插值高度的算法，使线条贴合实际渲染出的三角网格。
- **场线与标记浮离势面：** 地形只在网格顶点按 φ 映射高度，场线、选中电荷、探针和镜头焦点此前却在任意点重新计算连续公式高度，导致可见三角面与覆盖对象不完全重合。新增按网格对角线切分规则进行重心插值的表面高度采样，并统一用于场线、点标记、探针竖线和镜头焦点。
- **窄侧栏动作按钮难读：** 四个操作横排导致中文按钮逐字换行。为共享 SceneActions 增加两列网格布局，本场景改用两列；保留原横排/纵排行为。
- **数据面板遮挡：** 默认展开的浮动读数卡覆盖中心场景。改为桌面默认折叠，点击“展开”仍可查看；移动端数据仍在原数据页签。
- **模型描述不够精确：** 在参数说明中写出相对单位、软化公式和压缩高度公式，避免将显示高度误解为实际高度。
- **验收脚本过期：** 旧脚本仍按旧标题和旧读数 DOM 选择器定位，已改为当前路由、标题、说明和 DataReadout 结构，并补入 390px 页面溢出检查。

## Dmit 对照与未覆盖内容

Dmit 的原页侧重二维测量教学：A/B 点对照、零电势参考、场线与等势线关系、电势及场强图像和试探电荷做功。本地保留的是三维电势地形、多个静电预设、单点探针和编辑电荷，尚未覆盖 A/B 电势差、φ-x/E-x 曲线及做功流程。这是教学内容范围差异，不是当前模型公式错误；若目标改为复刻原页完整教学流程，应另行规划交互扩展。
