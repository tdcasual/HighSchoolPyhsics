# 发电机核心模型场景审计

### 参考比较

- 最接近的公开原理动画是 [PhET Faraday’s Electromagnetic Lab（Generator 屏）](https://phet.colorado.edu/sims/html/faradays-electromagnetic-lab/latest/faradays-electromagnetic-lab_en.html)及其[官方模型说明](https://github.com/phetsims/faradays-electromagnetic-lab/blob/main/doc/model.md)。PhET 的涡轮/水轮驱动条形磁铁旋转，磁铁的磁场变化作用于拾取线圈；本地场景采用固定 N/S 磁极和旋转线圈。两者结构不同，只对照磁通变化、感应电动势/电流方向等概念，不能称为照搬同一个装置。已跟踪的 Dmit 实验目录没有这套发电机模型。
- PhET 模型说明将涡轮描述为连接水轮的旋转条形磁铁，并说明拾取线圈通过磁通变化实现法拉第感应；这个参照说明了为何本地几何不应被说成 PhET 原件的复刻。[官方模型文档](https://github.com/phetsims/faradays-electromagnetic-lab/blob/main/doc/model.md)

### 审计发现与修复

1. **初始布局挤压并遮住装置。** 数据卡因动态解释长、宽度未受限而超出 1280×720 画面；展开的相位图和播放卡覆盖模型。现把数据卡限宽为 460px，并将读数压为相位/位置、归一化磁通、归一化电动势、切割比例、电流方向和一条动态解释；桌面相机移到侧栏与数据卡之间，图表和播放面板默认收起。浏览器复核后模型、数据卡和两张收起卡都在视口内。
2. **速度箭头没有指向实际运动导线。** 旧箭头从线圈上方的虚空位置出发，虽然随相位转向，却不是某段导线的速度。现把它锚定在线圈正 z 侧导线上，方向按线圈绕 y 轴旋转的切向速度更新。
3. **电流箭头脱离线圈走线。** 旧红/蓝箭头是线圈下方的一支水平箭头，无法表示回路电流。现将成对的反向箭头贴在线圈两条竖直导线段上；正、反电动势时箭头交换，接近零电动势的换向点隐藏箭头。0°、约 91°、约 277° 截图与读数分别显示不切割/零电势、正向峰值、反向峰值。
4. **相位图追踪线被钉在左侧。** `mapPoint(...)[0]` 取到 SVG 坐标字符串的第一个字符而非 x 坐标。现拆成数值 `mapX`/`mapY` 映射；新组件测试验证 0 相位在 x=34、π/2 在 x=127。浏览器截图显示约 91° 的游标及 Φ/e 两个采样点落在 π/2 象限，约 277° 落在 3π/2 象限。
5. **负半周的文字把磁通最小值误叫最大值。** 在 θ=π 时 Φ=−Φₘ，磁通是负极值。现将中性面说明改为 `|Φ|=Φₘ`，平行面说明改为 `|e|=Eₘ`，避免把负半周的极值说反。
6. **几何与符号核对。** N 在左、S 在右，场线从 N 指向 S；θ 是线圈法向量与 B 的夹角。`Φ/Φₘ=cosθ`、`e/Eₘ=sinθ`、`v⊥/v=|sinθ|` 与当前旋转约定一致。0° 时法向量沿 B、磁通绝对值最大、电势为零；90° 时磁通为零且切割/电势幅度最大；270° 时电势和电流方向反转。ω 只改变动画转速/周期，读数为相对峰值归一量，并未声称输出绝对伏特值。

### 验收证据

- 浏览器 1280×720：初始/固定角度模型在视口内；数据卡不溢出；相位图、播放面板默认收起，展开相位图仍不遮挡线圈。
- 固定 0°：Φ/Φₘ=1、e/Eₘ=0、切割比例0、电流为“换向瞬间”，线圈无红/蓝电流箭头。
- 固定约91°：Φ/Φₘ≈−0.02、e/Eₘ≈1、切割比例≈1、电流正向；约277°：Φ/Φₘ≈0.12、e/Eₘ≈−0.99、电流反向，图表游标同步。
- `npm test -- --run src/scenes/generator-core/model.test.ts src/scenes/generator-core/GeneratorCoreChart.test.tsx`：2 个测试文件、3 项通过。
- `npm run build`：通过；Vite 仍报告共用 Three.js chunk 大于 500 kB。
