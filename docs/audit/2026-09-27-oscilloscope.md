## 审计发现与修复

1. **默认信号全为零，进入页面只能看到中心光点。** 改为 X 轴 8*sawtooth(2*pi*2*t-pi)、Y 轴 6*sin(2*pi*2*t)。满偏 ±10 V 时该波形从屏幕左侧开始横向扫描，Y 轴在 ±0.6 范围内摆动。图表、数据、播放浮层默认收起，避免初始演示被卡片遮住；CRT 屏面现在直接显示网格和荧光轨迹。
2. **锯齿波相位没有从左边缘起扫。** 解析器的 sawtooth 定义在零相位处输出 0；旧预设因此从中线开始扫。给时基加 −π 相位后，测试锁定 t=0 为 −8 V、t=0.25 s 为 0 V、t=0.5 s 快速回扫到 −8 V。
3. **调“时间倍率”会把运行时间重置。** 旧 hook 把倍率写进 initialState.velocity，又打开 autoResetOnInitialStateChange；改倍率触发通用仿真重置。现在初始状态固定、速率只缩放 dt，并限制到 0.05–3×。交互实测：运行到 t=1.067 s 后切换到 2×，时间继续到 2.042 s，没有回到 0。
4. **CRT 视角把 X 偏转压成景深变化，电子枪被侧栏切掉。** 相机改成斜视屏面与管身的三分之四角度，视野放宽并左移瞄准点。1280×720 实测可同时看到电子枪、两组偏转板、管体和荧光屏；参数栏和浮层不再挡住枪口。
5. **荧光屏只有单个光点，持久波形藏在默认收起的独立图表中。** 将二维轨迹映射到 3D CRT 的荧光面，增加圆面内 10×8 刻度线和高对比度波形；二维图仍可从“图表”卡片展开。
6. **双轴同时满偏时，方形坐标映射会把光束推出圆形荧光面，二维轨迹和 3D 光点位置也会不一致。** 增加单位圆合成偏转限幅，并同时用于电子束路径、CRT 屏面轨迹、二维轨迹和当前光点；读数卡说明 X/Y 轴及合成圆屏分别何时限幅。Uₓ=Uᵧ=20 V 实测得到 x=y≈0.71，显示“圆屏合成偏转”限幅。
7. **公式输入边界。** 解析器使用白名单 AST，不调用 eval；现有测试覆盖常量、三角函数、函数元数、溢出和非法字符。浏览器输入 sin( 显示“公式语法错误：表达式不完整”；20 V 输入触发超量程状态和轴限幅。默认公式、相位扫描与双轴径向限幅都有回归测试。
8. **装置结构关系复核。** CRT 管轴沿世界 +X，荧光面法线沿 X；第一组 Y 板沿世界 Y 分开，第二组 X 板沿世界 Z 分开，屏面坐标按 X→Z、Y→Y 映射，符合两组相互垂直的偏转方向。三次贝塞尔束路只表示方向/形状，不计算板间受力；控件说明已明确这一限制。
9. **旧 model.ts 和 model.test.ts 没有生产代码导入；当前运行路径是表达式解析器与轨迹模块。** 曾尝试移除旧文件，但自动审查因可能删除用户未提交工作而拒绝；文件和测试均保留，不影响当前页面运行。后续可在确认其归属后单独清理。

## 验收证据

- 浏览器 1280×720：默认能看到电子枪、偏转板、透明 CRT、屏面网格和正弦轨迹；数据、图表、播放卡均为收起状态。
- 浏览器交互：1×运行中调到 2×，t 从 1.067 s 连续增长至 2.042 s；恢复基准后 t=0、倍率 1×。
- 边界状态：Uₓ=20 V 时显示 X 轴限幅；Uₓ=Uᵧ=20 V 时 3D 光点与二维轨迹都按单位圆限制，读数显示 X/Y 轴和合成圆屏限幅；sin( 显示具体语法错误。
- npm test -- --run src/scenes/oscilloscope：12 个测试文件、36 项通过，含邻近 oscilloscope-3d 结构测试。
- npm run build：TypeScript 和 Vite 构建通过。Vite 仍提示共享 Three.js chunk 大于 500 kB，这是项目级既有包体积告警。
- git diff --check：目标场景改动无空白错误。
