# 导体棒切割磁感线场景审计

日期：2026-09-27  
场景：`motional-emf`（导体棒切割磁感线）

## 参考对照与教学范围

- Dmit 免费原页：[实验 12 · 电磁感应：导轨上的滑杆](https://dmit.20030624.xyz/emf-rail.html?v=20260923-zoom3)。页面使用 2D 导轨、滑杆、闭合电路和电阻，逐帧显示 `E=BLv`、`I=BLv/R`、安培阻力、外力、加速度、终端速度与能量账本 `W_F=ΔEk+Q`。
- [OpenStax《University Physics, Volume 2》13.3 Motional EMF](https://openstax.org/books/university-physics-volume-2/pages/13-3-motional-emf)核对：垂直杆/速度/磁场的特例退化为 `ε=BLv`；一般方向从 `q(v×B)` 得到，并可先计算开路棒两端的电势差，不要求必须有真实闭合回路。
- 本地 3D 模型是通用矢量关系教学：改变 `B`、杆向量 `L`、速度 `v` 和夹角，观察带符号的 `U_AB`、正电荷受力方向和电表偏转。它不模拟 Dmit 的导轨/滑杆力学、安培阻力、终端速度和能量转换，也不是逐帧复刻。两个模型覆盖互补，保留本地 3D 的角度讨论范围。

## 公式及极性审计

场景把杆向量 `L_AB` 定义为从 A 端指向 B 端，显示 `U_AB=V_A−V_B`。因此模型计算 `U_AB=(B×v)·L_AB`；杆内正电荷受力/运动电流方向示意使用 `v×B` 在杆方向上的投影，两者符号相反是因为电压标签为 A 减 B。默认 `B=1 T` 向上、`L=0.5 m` 向右、`v=2 m/s` 向前时，`U_AB=+1.00 V`，A 端电势较高，杆内正电荷受力方向向 A；方向约定前后一致。

浏览器实测及现有模型用例核对：反转 `B` 后 `U_AB` 变为 −1.00 V；`v∥B` 时为 0；保持默认 B/L、令 `L` 与 `v` 成 30° 时为 +0.50 V。交叉乘积、杆长、速率和夹角关系一致。

## 审计发现与修复

1. **主要器材被浮层挡住**：原数据卡默认展开，独立播放卡浮在 3D 画布中间，遮住大半电表。播放/重置已移入左侧参数栏；数据卡默认收起；删去重复显示的角度关系摘要，保留状态、行程、电压、极性和三个夹角。
2. **磁场像密集栅栏，电表被画进场区**：原有 18 根纵向箭头在默认斜视中挤叠且穿过电表。改为 3×3 均匀场示意、缩短箭杆至与场区高度相符、使用半透明箭头和浅色网格；电表移至场区右侧，导线端点仍接回杆两端。
3. **俯视/底视只是按钮状态变化**：场景传入新的 camera/target，但 `InteractiveCanvas` 默认关闭相机同步，实际镜头不动。现显式启用 `syncCamera`，扩大顶/底视框选范围；测试增加同步开关断言，浏览器截图确认视角真的沿 B 轴切换。
4. **模型边界未说清**：控件现说明 `U_AB=V_A−V_B` 与 `U_AB=(B×v)·L_AB`，并说明测量导线是理想示意，只计算棒段动生电动势。绿色矢量名称改为“杆内正电荷受力方向（电流方向示意）”，避免把开路棒中的电荷分离误说成已建立真实闭合电流。

## 保留限制

场景没有真实导轨、回路电阻或机械受力模型；电表仅显示带符号的理想电势差，电表针角没有现实量程标定。测量导线的形状是连接示意，不计算导线运动造成的附加动生电动势。若教学目标改为终端速度、安培阻力或 `W_F=ΔEk+Q`，应进入 Dmit 导轨模型对应的另一类演示，而非把当前矢量场景称作完整复刻。
