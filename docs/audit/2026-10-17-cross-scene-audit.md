# 全场景交叉审计（2026-10-17）

范围：除游标卡尺/螺旋测微器外的全部 29 个活动场景（游标卡尺另见同日改动）。方法：1920×1080 与 390×844 真实浏览器截图（白天、夜间两套主题）、控制台错误采集、逐元素 WCAG 对比度检测、模型代码与公式抽查、`verify:ci` 全流程。

## 发现与处理

### 跨场景（共享组件 / 样式）

| 问题 | 影响 | 处理 |

对比度复测：两套主题下，除浮在 WebGL 画面上的 3D 标签（检测器无法取得背景色）外，无 < 3:1 的文字。

### 单场景

- **感应电流方向**：相机目标偏低偏左，条形磁铁整段行程被数据面板遮住。桌面端改为对准装置右侧并抬高；手机端保持居中。楞次定律方向逻辑核对无误（N 极向下接近 → 感应磁场向上 → 俯视逆时针；磁铁到线圈中心时电流归零）。
- **导体棒切割磁感线**：读数显示「A/B 端高电势」，但 3D 中无 A、B 标识。已在两端加 A、B 标签。符号约定核对无误（A 为左端，U_AB = (B×v)·L）。
- **双缝干涉**：目镜分划板 Δx 标尺用到 `filterColor`，但该 effect 未依赖它，白光下切换滤光片后 Δx 标尺不更新。已补依赖。另修两处 React 编译器 lint 错误。
- **示波器**：`useMemo` 依赖每帧变化、从未命中，且触发 lint 错误。已改为直接计算。
- **回旋加速器**：数据面板 7 行，含实现细节「自适应出发 y0」。精简为 5 行（AGENTS.md 要求 3–5 行），能量同时给出 J 与 eV。
- **交流发电机**：标签「单匝 Φ / e」易误读为单匝电动势（实为 N 匝总电动势），改为「Φ（单匝）/ e」。
- **示波器 3D**：缩略图中疑似「Y 偏转板（时基）」，放大核对为「X 偏转板（时基）」，无问题。

### 数值核对（均正确）

双缝 Δx = Lλ/d = 2.66 mm；单缝中央亮纹 2Lλ/a = 10.64 mm（L = 1 m）、5.32 mm（L = 0.5 m）；劈尖 l = λ/(2θ) ≈ 1.96 mm；交流发电机 Eₘ = NBSω = 14.26 V、I = e/R；奥斯特 B = μ₀I/(2πr) 与偏角；回旋加速器核心 Ek,max ≈ 360 keV；天体 v = √(GM/r)、T = 97.3 min、a = 8.116 m/s²；理想气体 p = nRT/V = 0.70 atm；等量异种电荷 E₁、E₂、φ；旋转切割 ε = ½BωL²；磁流体 ε = I(Rᵢ + R_L)；多用电表 2.5 V 挡 0.628 → 1.57 V。

所有基于 `requestAnimationFrame` 的仿真均按实际时间步进（固定步长累加或 dt），不受显示器刷新率影响。

### CI

审计前 `verify:ci` 有 12 个测试失败、4 个 lint 错误、电阻率场景超出 240 行预算。测试失败均为上一轮改动后未同步的断言（标签更名、面板默认折叠），已按当前行为更新。电阻率与游标卡尺场景中重复的 `useViewportSize` 抽为共享 hook，格式化函数移入 `resistivity/format.ts`。新增 CSS 一度使入口 CSS 超出预算，已删除无引用的 `.map-*` 旧样式（约 3 KB），入口 CSS 现为 62.6 kB / 65 kB。

### 数据面板默认展开（用户决定）

原有 19 个场景以 `dataInitiallyCollapsed` 默认折叠数据面板，违反 AGENTS.md 原则 2。经确认已全部改为默认展开，并逐一复查遮挡：

- 回旋加速器：图表面板原默认展开且覆盖几乎整个 D 形盒，改为按需展开。
- 劈尖干涉、光的衍射、奥斯特实验：数据或播放面板遮住光源、光具座前端、电池与导线，桌面端相机已平移避让（手机端构图不变）。
- 相关结构测试改为断言数据面板默认展开（按钮为「折叠」）。

## 第四轮：游标卡尺 / 螺旋测微器取景与背景

- 取景改为按浮动面板的实际位置计算（`framing.ts` + `useOverlayObstacles`）：测量侧栏、数据 / 图表 / 播放面板和操作提示的位置，在剩余空白中选出让仪器显示最大的矩形。面板收起、关闭、改变大小或拖动结束后会重新取景。1920×1080 下卡尺全景的相机距离从 692 缩短到约 510，仪器放大约 35%；收起图表后卡尺会继续变大。
- `SceneBackdrop` 修复：原先用 JSX 的 `attach="background"` / `attach="fog"`，但这只会挂到直接父节点上；放在 `<group>` 里时，背景色和雾都不生效，画面上露出的是页面底色，地面边缘因此出现一条地平线。现在改为直接设置 `scene.background` / `scene.fog`。共用该组件的小车、天体、多用电表、电阻率场景已复查，显示正常。
- 测量工具的地面改为不受光照、不做色调映射的材质，由雾渐变到背景色，不再出现明暗分界。
- 仍待处理：电磁驱动、波的状态等场景直接写 `<color attach="background">`，其中波的状态写在 `<group>` 内，可能同样不生效，需要逐个核对。

## 第五轮：按教学目的调整架构（2026-10-19）
