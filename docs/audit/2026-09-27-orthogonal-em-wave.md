# 电磁波空间正交传播模型审计

日期：2026-09-27  
场景：orthogonal-em-wave

## 参考与模型边界

Dmit 公共实验目录及交互实验页检索未发现与本场景同构的三维正交电磁波传播动画，因此不声称逐帧复刻 Dmit。物理方向关系按 OpenStax《University Physics Volume 2》核对：[§16.2 Plane Electromagnetic Waves](https://openstax.org/books/university-physics-volume-2/pages/16-2-plane-electromagnetic-waves)说明电场、磁场和传播方向互相垂直；真空中波速为 c=1/√(ε₀μ₀)，且 E/B=c。[第 16 章公式表](https://openstax.org/books/university-physics-volume-2/pages/16-key-equations)列出能流密度矢量 S=(1/μ₀)E×B。

本场景是归一化的方向与相位教学模型：场强使用 a.u.，速度滑杆是 vₛᵢₘ，不是光速，也不表示 SI 量纲下 E/B 的数值。界面明确指出真空电磁波应满足 v=c、E₀=cB₀。因此模型用于观察互相垂直关系、左右传播和符号变化，不是完整的 SI 电磁波求解器。

## 审计发现与修复

1. **反向传播的磁场符号错误。** 空间相位会随传播方向反转，但磁场分量曾继续沿固定正 z 方向；这样左行时 E×B 仍指向 +x，与传播方向冲突。现在左右传播分别令 B_z=+Eᵧ 与 B_z=−Eᵧ，保证 E×B 与传播方向一致；场线、箭头、读数和探针都共用同一模型。
2. **模拟参数容易被误读为真实光速关系。** 速度和频率原按滑杆可调，但单位说明不够突出。现将参数标为“仿真传播速度 vₛᵢₘ”和“仿真频率 fₛᵢₘ”，电场/磁场振幅标为归一化 a.u.，并在数据说明中区分真空中的 c 与仿真时钟。
3. **初始视图被浮层占据。** 数据、图表和播放控制曾默认展开，遮住场线。现默认折叠；窄桌面将侧栏后的数据/图表垂直堆叠，图表宽度限制为 300 px。窄桌面画布标题与侧栏场景名重复，且会被侧栏/浮层遮挡；现在 768–1100 px 时隐藏该重复画布标题，侧栏仍保留“正交电磁波模型”。场景把同一个断点从外层布局传给 3D rig，避免 Canvas 实际宽度和窗口宽度不一致导致断点失效。
4. **YZ 正视图的传播信息不完整。** 沿 x 观察时 x 轴投影退化成零长度线，容易显示成多余线段。现隐藏该轴及其标签，直接标出 Eᵧ、B_z，并按方向显示 ⊙（朝向观察者）或 ⊗（背离观察者）。
5. **箭头和屏幕空间标签。** 3D 方向箭头原较密，移动端标题和场标签容易碰撞或被裁切。现 3D 箭头每隔一个采样点绘制，传播方向线带明确箭头；手机视图分别检查标题、E/B 标签、坐标轴标签和 YZ 方向符号的边界及相互遮挡。
6. **播放状态表达。** 场景现在从静止的 t=0 开始；按钮按状态显示开始、暂停或继续。图表与时钟状态同步，可暂停后检查固定相位，不会一进入页面就改变读数。
