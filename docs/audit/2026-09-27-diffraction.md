## 参考比较

- [Dmit 光的衍射演示](https://dmit.20030624.xyz/diffraction.html?v=20260927)是二维定性模拟，可切换单缝、圆孔、方形、三角形、六边形、十字和双缝，查看屏面和曲线。页面说明其孔径掩模 FFT 图样、弱条纹亮度压缩及 Fresnel 数混合。本地是光具座和屏幕的 3D 示意，提供单缝、圆孔、圆盘遮挡体和光栅；后两者是本地扩展，Dmit 的多边形孔形没有逐项照搬，因此不是外观相同的复刻。
- [TU Delft 衍射光学教材](https://interactivetextbooks.tudelft.nl/tn2421/content/Chap6_Diffraction/DiffractiveOptics_2022_01Clean.html)区分近场 Fresnel 与远场 Fraunhofer 条件。本地三个远场模式使用 Fraunhofer 公式，这也是本次参数范围审计重点。

## 发现与修复

1. **远场公式曾用于近场参数。** 大孔径、短波长和短屏距组合会有较大 Fresnel 数。单缝、圆孔、光栅现自动满足保守条件 `F=b²/(λL)≤0.1`；白光取最短波长 400 nm，孔径取半宽，光栅取照明宽度的一半。滑杆下限、状态纠正和说明同步更新。屏距显示向上保留 0.001 m，避免浮点值看起来小于下限。圆盘模式单独标为泊松亮斑近轴近似，不称为完整 Fresnel 解。
2. **光栅有效狭缝数单位错误。** 线密度单位是线/mm，照明宽度固定为 0.5 mm，因此 `N=0.5×线密度`，范围 50–300。原计算把 N 错误限制在约 10。读数现按单位正确计算；3D 槽纹仍是放大的结构示意，狭缝宽 `a=0.2d` 也是模型设定。
3. **白光滤光片读数忽略所选波段。** 屏纹理已使用 raised-cosine 通带，但数据读数此前仍按 400–700 nm 全谱计算，旧入口的缓存依赖也漏掉滤光片状态。两个入口现都将选定的红/绿/蓝波段用于特征范围计算，并随筛选刷新。
4. **屏幕坐标和高极值视场不统一。** 平面屏使用 `sinθ=y/√(L²+y²)`、`y=L tanθ`；单缝宽度、圆孔艾里斑、光栅一级位置共享这套几何。纹理做子像素积分、曲线加密采样，坐标轴比例保持一致，视场按当前特征扩展，避免窄纹丢失、条纹越屏或无穷值污染画布。
5. **3D 屏面没有衍射纹理且被装置遮挡。** 现把强度纹理贴在垂直于光轴的屏面，使用开放环形支架；无光时屏面熄灭。孔径板有真实开口，圆盘模式保留不透明遮挡体。移除了挡屏且没有对应交互的末端目镜。
6. **平板及默认视图被浮层挤占。** 图表和数据卡默认收起，屏幕、栏杆和标注随屏距移动；平板布局将相机目标移向屏幕并拉远，数据卡固定宽度并允许范围值换行。

## 计算范围与限制

- 单缝：`I∝(sinβ/β)²`，`β=πa sinθ/λ`；圆孔：`I∝[2J₁(x)/x]²`，首个 `J₁` 零点给出艾里斑半径；光栅：`d sinθ=mλ` 并乘单缝包络。
- 圆盘泊松亮斑使用近轴 `J₀²` 径向近似，未求完整有限距离复振幅 Fresnel 积分。
- 参数约束只保证远场公式在声明的教学范围内，未实现 Fresnel 传播。3D 尺寸、槽纹数量比例、屏幕颜色/亮度都是示意。白光采用离散波长和近似 RGB 映射，不是标准色度重建。
- 完全提供 Dmit 的多边形孔形需要新增衍射模型和 3D 遮罩，属于尚未实现的功能。
