# 3D 示波器与波形测量场景审计

### 参考比较

- [Dmit 电场加速与偏转](https://dmit.20030624.xyz/electric-deflection.html?v=20260923-zoom3)是最接近的现成物理装置参照：展示电子经加速电压获得速度，并在偏转电场中产生屏上位移，给出 `v₀=√(2qU₁/m)`、`y=U₂L²/(4U₁d)`。它不含扫描时基、触发同步、VOLTS/DIV、TIME/DIV 或示波器测量读数，所以只能核对“偏转板—屏上位移”的方向和教学关系，不能称为本地 3D 示波器的同款/原版。
- 本地场景侧重示波器读数和 X-Y 轨迹；其 3D 束流是按屏幕刻度映射的示意线，UI 已明确说明并不求解 U₁/U₂ 与 q/m 的粒子运动。避免把示意几何误当成 Dmit 粒子方程的数值结果。

### 审计发现与处理

1. **荧光屏轨迹几乎不可见。** 浅色波形线与屏幕底色相近，并容易被屏幕/透明管体的深度遮挡。现改成高对比度、屏幕前表面发光带，强制通过透明外壳可见；束流端点也落到可见荧光面。默认 1280×720 截图可清楚辨认正弦轨迹。
2. **X-Y 等振幅圆被拉宽。** 屏幕网格为横向 10 格、纵向 8 格，但原模型把 X、Y 两轴都除以 4；3×3 div 的圆预设实际横向达到 3.75 格。现 X 轴按 5 格半宽归一化、Y 轴按 4 格半高归一化，并添加物理屏幕单位下的圆半径相等断言。视觉上轨迹现在是圆（视角透视会产生轻微投影压缩）。
3. **偏转板和屏幕尺寸需与玻璃管约束一致。** 屏幕改为 10×8 格、3.2×2.56 单位，矩形半对角约 2.05，小于管体半径 2.15，网格角点不再穿出管壁。X 偏转板中心从 z=±1.05 调整到 ±1.2；按最大屏幕偏转检算，束流在板末端仍留有间隙。电子枪锥尖指向管内 +X。
4. **束流端点与屏面深度关系偏后。** 末端从屏面后方微调至可视荧光面；Y 板前束流保持近轴直行，在 Y 板区域开始偏转，离开 Y 板后继续弯曲。高振幅时轨迹和光点受屏幕刻度钳制，测量卡显示“超出屏幕垂直范围”警告，而不是让几何穿出玻璃管。
5. **桌面视图被右侧浮层夹压。** 调整 3D 视角的目标与距离，默认收起图表和播放卡。1280×720 下模型完全落在控制侧栏和右侧卡片之间，荧光屏边缘不与浮层重叠。
6. **公式和读数核对。** `Uₚₚ=2Uₘ`、`T=1000/f`、垂直格数 `Uₚₚ/(VOLTS/DIV)`、水平格数 `T/(TIME/DIV)` 与模型一致；触发模式只固定波形相位，自由模式随时间漂移。扫描时基覆盖 10 个水平格，单周期水平格数由 T 和 TIME/DIV 求得。

### 验收证据

- 浏览器默认结构模式、扫描模式、波形测量模式、X-Y 圆预设均可加载；荧光轨迹可见，右侧面板无重叠。
- X-Y 默认同频、90°、3×3 div：屏幕单位下 X/Y 半径相等；模型测试锁定该不变量。
- 波形测量最大测试值 `Uₘ=4 V, f=500 Hz, VOLTS/DIV=0.5 V, TIME/DIV=0.5 ms` 显示 `Uₚₚ=8 V`、`T=2 ms`、`16×4` 格，并显示垂直越界警告；轨迹仍限制在荧光屏网格内。
- `npm test -- --run src/scenes/oscilloscope-3d/model.test.ts src/scenes/oscilloscope-3d/__tests__/structure.test.tsx`：2 个测试文件、6 项通过。
- `npm run build`：通过。Vite 仍报告共用 Three.js chunk 大于 500 kB，这是项目既有包体积告警。
