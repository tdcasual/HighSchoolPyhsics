# 电荷等势面场景审计

审计日期：2026-09-27  
场景路由：/equipotential  
审计对象：src/scenes/equipotential

## 参考比较与范围

- Dmit 原页：[电场线与等势线·电势能和电势](https://dmit.20030624.xyz/field-lines.html?v=20260923-unequal)，页面标注高中必修内容衔接；现场核对 1440×1000 页面。原页是二维综合实验，包含 8 种场源分布、场线和带电势标签的等势线、E 与等势线正交提示、A/B 测点读数、φ-x/E-x 图像以及移送电荷和路径做功。
- 本场景是可编辑多电荷的三维等势面模型，不是 Dmit 页面的逐项复刻。它专注呈现空间曲面和电荷位置/电量对曲面的影响；本场景不含 Dmit 的场线、测点、电势图和做功流程，不能以曲面替代这些二维定量实验。Dmit 原页无三维曲面对照项。
- 物理基准：[OpenStax：点电荷电势与叠加](https://openstax.org/books/university-physics-volume-2/pages/7-3-calculations-of-electric-potential)给出点电荷电势及多源叠加关系。当前代码按相对单位计算并省略库仑常量；使用软化核是为了让数值网格上的点电荷奇点有限，不把结果标为伏特。

## 模型和结构核对

- 代码实现：φ_rel = Σ qᵢ / √(rᵢ² + ε²)，ε = 0.18 模型坐标单位。正负源作线性叠加，q 与输出均为相对量；这不是 SI 电势，也不是未软化的理想点电荷解。
- 等势面由三维电势规则网格经过一致六四面体分割提取三角曲面；共享交点按坐标焊接成索引网格，重新计算顶点法线。正势红色、负势蓝色，电荷球大小只表示相对电量，不表示真实半径。
- 视图范围为每轴 ±5，编辑源现在限制在每轴 ±3，自动添加电荷也限制在半径 3 以内。坐标范围和 ε 均是模型单位，不作长度单位解释。

## 发现与修复

1. **曲面可能穿过采样盒边界。** 旧算法直接按采样网格最大/最小电势的比例取层值。网格变稀或源点不落在采样节点上时，软化点电荷峰值会被低估，低电势等值层可能延伸出盒外，导致曲面在视图边缘被切断。现在先区分盒面极值和内部极值，再在两者之间插值正、负势层值；只提取能闭合在采样域内的等势面。
2. **电荷编辑位置可把源推到视图边缘。** X/Z 原先可到 ±4.5，Y 可到 ±3.5，而采样域每轴仅 ±5。三轴统一收紧到 ±3，自动新增源半径上限设为 3，为闭合曲面留出空间。
3. **简化公式的教学边界不够明确。** 原界面只提到软化，没有把公式、相对单位及省略的库仑常量说清。现在控制区显示软化叠加式，并说明数值不是伏特；数据范围也标成“网格相对电势范围”。
4. **曲面是否真实连续、闭合缺少证据。** 保留三角化面，并增加回归验证：对中心单源、靠近编辑范围边缘的单源、双极子，使用最低 14³ 采样密度和 6 层极限检查两种极性曲面的每条网格边均被恰好两个三角形共享；中心单源曲面顶点的电势误差另有数值阈值校验。
5. **视图和编辑入口。** +/− 电荷符号、XYZ 轴端标签与当前选中环均可见；数据卡默认收起，桌面和手机分别调整相机。最多 12 个场源，达到上限后禁用添加按钮；密度上限跟随性能档位。
