# 回旋加速器核心结构与原理审计

日期：2026-09-27  
场景：cyclotron-core

## 参考与范围

Dmit 公共实验目录中没有找到同构的回旋加速器核心结构动画，因此本次不声称逐帧仿制 Dmit。结构和公式按 [OpenStax University Physics Volume 2, §11.7](https://openstax.org/books/university-physics-volume-2/pages/11-7-applications-of-magnetic-forces-and-fields) 核对：两个半圆形 D 盒之间留狭缝；电场只在狭缝加速粒子；垂直磁场在盒内使粒子偏转；非相对论近似下 r=mv/(qB)、T=2πm/(qB)，每次过缝增加约 qU 动能。

## 发现与修复

1. **电极形状与间隙。** 上下灰色区域原先是偏移圆形，与轮廓不共圆。改为同半径的上下半圆切面和一致间隙，并给电极增加薄的实体厚度。
2. **离子源、电源和极性。** 原图把离子源画在设备外，电源接线含义不清。现将离子源放在中心，外部高频电源独立显示，分别接入上下 D 盒；狭缝箭头按“正极指向负极”的电场方向变化，电源极性在每次半圆运动中途翻转。
3. **轨迹几何。** 原轨迹的第一段从原点斜连到半圆采样点；各段圆弧未依据前一过缝点移动圆心；播放中的半圆只连到当前位置，显示成弦。现从中心离子源开始构造交替的上、下半圆，轨道半径随 qU 增加；半圆端点连续衔接在狭缝上，运行中按角度采样绘出真实弧线。整段示意轨迹按设备边界统一缩放，避免穿出 D 盒。
4. **射出束流。** 原模型已把射出线加入轨迹，渲染层又画了一条相同方向的线，导致束流加倍、粒子标记落在中间。现将射出束流只绘制一次，起点在最后一个过缝点，沿末段切线伸出；粒子和文字标记与该线段对齐。
5. **能量和上限。** 每次过缝的动能增量按 qU 计算，回旋半径按 √E 增长，理论上限按 q²B²R²/(2m) 计算。系数 40 keV 明确绑定有效参考半径 R≈2.87948 cm（质子、B=1 T），不再留下无来源常数。零能量时半径为零；最大动能处停止并显示射出状态。
6. **时间与状态。** 动画时间按 qB/m 保持粒子间相对回旋周期关系，但未伪装为 SI 秒。初态改为停止且动能为零；参数变化会清空旧轨迹并停止播放；达到提取条件后停止，需重置再运行。
7. **视图遮挡。** 默认折叠数据、图表和播放面板；数据卡改成窄单列，装置轻微右移，使展开数据时轨迹保持可见。电源标签在桌面和 390 px 手机宽度内完整显示。

## 模型边界

轨迹和播放时钟是用于教学关系的归一化示意，不是带边缘场、RF 相位误差或相对论修正的数值粒子求解器；可视轨道经过边界缩放，不能用画面长度直接量出厘米。磁场叉号、箭头和电源符号均为结构示意。界面提示了非相对论和示意轨迹限制。
