# 简谐横波传播状态模型审计

日期：2026-09-27  
场景：`wave-state`

## 参考与边界

Dmit 公开交互实验目录的检索未发现与“有限介质中波前到达、质点起振、指定质点位移图”直接同构的页面，因此本记录不声称逐帧复刻 Dmit。物理关系按 OpenStax《University Physics Volume 1》核对：[§16.1 Traveling Waves](https://openstax.org/books/university-physics-volume-1/pages/16-1-traveling-waves) 给出 `f=1/T`、`v=λ/T=λf` 及介质点振动与波传播的区别；[§16.2 Mathematics of Waves](https://openstax.org/books/university-physics-volume-1/pages/16-2-mathematics-of-waves) 用 `kx∓ωt` 的相位符号表示相反传播方向，并给出 `v=ω/k`。

## 审计发现与修复

1. **传播与起振物理。** 代码按 `v=λ/T` 求波速；有限弦长 `L=8 m` 上，向右波的到达时刻为 `τ=x/v`，向左为 `τ=(L−x)/v`。波前到达前质点保持 `y=0`，到达后按 `y=sA sin[2π(t−τ)/T]` 振动，`s=+1/−1` 表示向上/向下起振；速度与加速度分别由位移时间函数求导，`a=−ω²y`。当前模型与参考关系一致，未发现公式符号错误。
2. **初始播放状态。** 场景原先一进入就开始运行，用户看到时刻可能已离开 `t=0`；数据和图表也同时占据动画区域。现改为从暂停的 `t=0` 开始，数据与图表默认折叠；操作按钮明确区分开始、继续和暂停。
3. **预设和说明。** “振幅×2”此前从当前振幅翻倍后受上限截断，某些状态下并非两倍。现在它重置为 `A=50 cm` 基准情景并设为 `A=100 cm`。同介质 `f×2` 同时减半 `λ` 和 `T`，保持波速不变。说明区补充了分方向的波前到达式、弦长与起振正负号。
4. **质点和图像对应。** 分数米探针原来没有竖向位置引导。现对非整数质点也绘制竖直虚线和探针标记，位移—时间图从该点的波前到达时刻开始显示振动。
5. **标签越界。** 手机宽度下，振源、`y/cm` 与 `x/m` 标签原先会从画布边缘裁切。现将标签锚点移入介质区域，并保留向左传播时靠右侧的振源标记；在 390 px 宽度下两种传播方向的标签均通过边界检查。
6. **面板遮挡与跨路由样式污染。** 桌面图表与数据卡原先重叠约 41 px。测量工具的全局 `.measure-chart-content` 最小宽度还会在 SPA 切换后撑宽其他场景的图表。现将该类改为 `SceneLayout` 的显式可选样式，只由测量工具和电阻率场景启用；横波图表缩至其浮层可用宽度。桌面初始展开数据与图表时两者不再重叠；从测量工具同页切入横波的回归场景也验证通过。

## 模型边界

本场景展示理想的一维横波和固定介质点，不模拟介质色散、耗散、非线性或真实绳索的三维形变。`时间流速`只改变演示时钟，不改变物理周期和波速关系。波形参数变化后时间归零，避免把旧相位状态混入新参数。
