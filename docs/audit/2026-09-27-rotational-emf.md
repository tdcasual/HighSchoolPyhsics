# 旋转切割磁感线场景审计

日期：2026-09-27  
场景：`/rotational-emf`（旋转导体棒、旋转矩形线框）

## 参考与适用范围

- 在 Dmit 的公开实验目录中没有找到旋转导体棒或旋转矩形线框的同款交互场景，因此不把本场景描述成 Dmit 的复刻。几何和教学关系按公开教材核对。
- [OpenStax University Physics Vol. 2 §13.3：Motional Emf](https://openstax.org/books/university-physics-volume-2/pages/13-3-motional-emf) 展示绕轴转动的金属棒，并从 `|ε| = B∫ωrdr` 得到 `½BωL²`；同节也讨论旋转线圈的磁通变化。
- [OpenStax §13.6：Electric Generators and Back Emf](https://openstax.org/books/university-physics-volume-2/pages/13-6-electric-generators-and-back-emf) 给出 `ε = NBAω sin(ωt)` 和 `εₘ = NBAω`。本场景线框取单匝正方形、边长 `L`，角度 `θ` 从“磁场平行线框面”的初始状态计，所以磁通与 `sin θ` 成正比，感应电动势大小为 `BωL²|cos θ|`；这与教材把角度从线框法线与磁场之间量起的写法相差 90°，物理关系一致。

## 审计发现与修复

1. **线框角度公式和说明冲突。** 控件把 `θ=0°` 定义为磁场平行线框面、此时电动势最大，代码却用 `|sin θ|` 令其为零。改为 `|cos θ|`，并用 `θ=0°`、`90°` 两个状态回归验证。
2. **旋转速度依赖屏幕刷新率。** 原状态每帧固定加角度，未按时间积分。改为按 RAF 时间戳累计 `ω·Δt`，并限制单次长帧步长；显示角度与公式读数共享同一状态。
3. **导体棒的轨迹环与旋转平面分离。** 环原先位于棒下方的网格平面，既不与棒端共面，也容易被误解成独立导轨。现把环移到棒的 XZ 旋转平面，并与棒端半径对齐；图例说明它是端点轨迹示意，不是闭合回路。
4. **长度滑杆和三维比例不统一。** 棒长与线框边长原本采用不同场景比例，部分棒粗细、线框接点和场箭头也不随长度同比例变化。现在两种模式统一按 `3.4` 场景单位/m 示意缩放，线框边长、棒长、轴件、场箭头及网格随 `L` 一致缩放；公式仍使用物理长度 `L`（m）。
5. **相机预设不会应用到正在运行的 Three 相机。** 主/俯视切换及长度变化曾只更新 React props。该场景现在启用共享 `InteractiveCanvas` 相机同步，显式同步 camera up、位置、视场与 OrbitControls 目标；关闭自适应取景对预设的二次偏移，并依据各模式边界动态取景。棒的轨迹圆、线框场箭头和两种模式的长度极值均完整入镜。
6. **线框主视角不利于观察转动，场方向箭头遮挡器件。** 默认斜视角接近对称方位，线框转过直角仍显得相似；原箭头也过密并穿过框线。线框主视角改为略俯视的正面视角，四根 `B` 箭头放在线框上下、框面之外；俯视保留为沿转轴观察，并提示此投影下线框自然呈边缘线。棒模式场箭头减为四根并移出中心轴线，减轻遮挡。
7. **默认浮层挡住装置。** 数据卡与播放卡原先默认展开、位于模型中央附近。现在默认折叠并排在控制侧栏旁；浏览器验收同时检查两卡展开后仍上下分离。
8. **模型范围未说明。** 读数仅给电动势绝对值，不计算闭合回路电流、极性、外电路或非均匀磁场。界面现明确为示意模型，并在公式旁说明线框角度约定与视觉比例。

## 验收证据

- 定向 Vitest：旋转电磁感应目录 4 个测试文件、13 项通过；包含棒转角无关、线框 `θ=0°` 最大且 `θ=90°` 为零、主视/俯视预设切换和浮层默认折叠。
- Playwright 脚本：[rotational-emf-audit.mjs](../../scripts/playwright/rotational-emf-audit.mjs)。在 1440×900 桌面及 390×844 手机验证两类视角切换、装置模式切换、线框播放/暂停时的实体转动、角度—电动势联动、复位、两类 `L=0.2…3.0 m` 取景、浮层避让和横向溢出；浏览器无运行错误。主/俯视截图像素变化分别为桌面 11.87%、手机 20.45%；线框转动前后的实际模型画面变化 1.37%。
- 公式读数验收：默认棒 `0.50 V`；线框 `θ=0°` 为 `1.00 V`、接近 `90°` 时趋近 `0 V`；`L=3.0 m` 和 `0.2 m` 分别读出 `9.00 V`、`0.04 V`（`B=ω=1`）。`ω` 设为 `3 rad/s` 时棒读数为 `1.50 V`，说明棒模型不随转角变化。
- 人工检查桌面主视/俯视、框旋转后、线框最大/最小长度和棒端轨迹：框线没有被磁场箭头盖住，圆环与导体棒共面，取景无裁切。手机线框俯视呈线边投影，符合沿转轴方向观察的几何关系。
- `npx eslint src/scenes/rotational-emf src/scene3d/InteractiveCanvas.tsx scripts/playwright/rotational-emf-audit.mjs` 通过（只有仓库 Browserslist 数据过期提醒）。`git diff --check` 通过。`npm run build` 的 TypeScript 与 Vite 构建通过；仍提示共享 Three.js 核心 chunk 大于 500 kB，此为现有项目级体积提醒。

## 剩余模型边界

该教学演示只输出电动势大小。导体棒环是端点运动轨迹，不是电路；线框为单匝理想正方形，磁场画成定性均匀矢量。它不模拟电荷运动、感应电流、正负极性、材料电阻或负载。
