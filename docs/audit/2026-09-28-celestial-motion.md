# 天体运动场景审计

日期：2026-09-28  
场景：/celestial-motion  
参考：[Dmit 天体运动演示](https://dmit.20030624.xyz/celestial-motion.html?v=20260923-spin)

## 对照范围与结果

检查圆轨道、倾斜同步轨道、追及会合、霍曼转移四类情境；核对默认参数、读数公式、轨道几何、滑杆边界、相机视图和浮层布局。

- 地球圆轨道默认读数为 r=7008 km（1.10R）、v=7.542 km/s、ω=1.076×10⁻³ rad/s、T=97.3 min、a=8.116 m/s²；第一宇宙速度 7.910 km/s、第二宇宙速度 11.186 km/s。与 Dmit 同组读数一致。
- 倾斜同步轨道默认值为 r=42164 km、倾角30°、周期23.93 h、速度3.075 km/s。追及会合与霍曼转移的预设参数及 vis-viva、开普勒周期、同步半径、会合周期和两次变轨 Δv 计算均与参考值核对。
- 场景关系式以 GM=g₀R²、v=√(GM/r)、ω=√(GM/r³)、T=2π/ω 为基础；转移轨道以 vis-viva 关系计算速度，并分别按近地点/远地点速度差计算两次 Δv。

## 发现与修复

1. **星下点与倾斜轨道坐标不一致。** 卫星位置使用固定升交点角，星下点公式却忽略该角，倾斜同步模式中实体位置、轨道平面和经纬读数不能完全对应。Dmit 源代码也有同一约定不一致。本地统一节点定义，并增加卫星与星下点一致性测试。
2. **追及扇区时间含义不一致。** 内外轨扇区原先使用固定角宽，代表的时间长度不同。现按同一 Δt 计算两个角宽，使两扇区表达同一时间区间。
3. **轨道半径控件可构造交叉轨道。** 外轨半径下限过去固定为1.2R，内轨半径升高后可能出现 q₂<q₁。现按内轨半径动态限定外轨最小值，并在切换至追及/转移模式时修正无效状态。
4. **预设倾角与控件粒度不一致。** 近地、会合和转移预设值现分别与 Dmit 对齐为30°、20°、25°，并与 5° 滑杆步进一致。
5. **轨道在视锥边缘裁切，面板挡住标记。** 相机按轨道包络、视场角和视口宽高比计算安全距离与中心偏移。图表和播放面板默认折叠并移到参数侧栏外侧的空白带；修复拖动面板在初始位置与偏移同时变化时重复叠加位移的问题。
