# 课堂展示设计原则（五区浮层布局）

本文档定义课堂展示的布局标准，用于指导后续所有新建演示页面。

## 1. 设计目标

- 让教师在 1080P 大屏上快速进入"可讲状态"：打开场景即有可讨论的画面，一次点击（或空格）即可播放。
- 3D 动画全屏铺底，核心控件和数据以浮层/侧栏形式覆盖，不抢占动画空间。
- 投影距离下可读：核心读数、图表与 3D 标签默认放大（课堂大字）。
- 移动端（≤767px）自动切换为 viewport + 底部面板布局。

### 1.1 运行时边界

- 课堂模式契约建立在现代 Chromium 教学环境上（`Worker` + `WebGL2` + `Pointer Events`）。
- 本文档不定义弱环境降级策略；能力不足由应用统一"运行环境不支持"阻断页处理。

## 2. 五区布局架构

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏：返回导航 · 白天/夜间 · 讲解 · 大字 · ?              │
├─────────┬───────────┬────────────────────────────────────┤
│ 参数控制 │ 数据       │                                    │
│ (侧栏)   │ (3–5 行)   │                                    │
│         ├───────────┤        3D 安全区                    │
│ 控件     │ 图表(按需) │   （场景构图在打开时映射到这里）      │
│ 操作提示 ├───────────┤                                    │
│ 颜色图例 │ 播放控制   │                                    │
│ ▸教师备注│           │                                    │
│ 320/44px │  面板列    │                                    │
└─────────┴───────────┴────────────────────────────────────┘
                      动画区 (3D) 全屏底层 z-0
```

### 区域属性

| 区域 | 默认状态 | 位置 | 折叠行为 | 可关闭 |
|---|---|---|---|---|
| 动画 | 始终可见 | 全屏底层 z-0 | — | 否 |
| 参数 | 展开 | 左侧栏 320px (z-30) | 折叠为 44px 窄条 + 展开按钮 | 否 |
| 数据 | 展开 | 面板列第 1 块（紧贴侧栏右侧） | 折叠为标题栏 | 否 |
| 图表 | 按需（多数场景默认折叠） | 面板列第 2 块 | 折叠为标题栏 | 是，可从底部「显示图表」恢复 |
| 播放 | 展开 | 面板列第 3 块 | 折叠为标题栏 | 是，可从底部「显示播放控制」恢复 |

所有场景只有一种面板位置：数据 → 图表 → 播放 纵向叠放在侧栏右侧的一列中。不再提供 `panelPlacement` / `chartOffsetY` 等逐场景偏移。

## 3. 核心原则

1. **3D 优先**：动画区始终全屏铺底，其他区域以浮层覆盖，不分割视口。
2. **一次取景，之后只遮挡**：`InteractiveCanvas` 在场景打开时测量侧栏与面板列，把场景的整体构图平移、缩放到右侧的 3D 安全区（只改投影，不移动相机）。之后展开/折叠/关闭/拖动面板或收起侧栏都只是遮挡或让出画面，不重新取景，教师调好的缩放与视角保持不变。场景相机按"居中构图"设计，不要再为避让面板单独偏移相机。
3. **数据随时可见**：数据浮层默认展开，只放 3–5 行课堂结论量；侧栏里已有的参数不在数据面板重复。
4. **解释放备注**：模型假设、公式推导、符号约定写进侧栏末尾折叠的「教师备注 · 模型与公式」（`SceneLayout` 的 `notes`，或控件里的 `<ModelNote>`）。侧栏正文只保留控件、操作提示与颜色图例。
5. **图表按需**：图表浮层可折叠/关闭，关闭后可从底部恢复。
6. **播放一步到位**：播放面板默认展开；空格键对应 `key` 为 `play` / `toggle-running` 的播放动作。凡是"开始/暂停/重置"类操作都放进 `playbackActions`，不放侧栏。
7. **打开即可讲**：场景默认状态应已有可讨论的画面（例如电势图先显示切片、波的状态停在波前到达 P 点之前）。
8. **投影可读**：课堂大字（默认开，快捷键 L）在 ≥1280×760 屏幕上把数据面板放大 1.5 倍、图表 1.25 倍、3D 标签 1.4 倍。
9. **讲解模式**：顶栏「讲解」或快捷键 P 隐藏顶栏、侧栏、图表与播放面板并全屏；数据面板保留在左上角（可折叠）。Esc 退出，空格仍可播放/暂停。
10. **先预测后揭晓**：结论性读数用 `<Answer>` 包裹。数据面板标题栏「预测」（快捷键 H）把它们遮成「?」，图表一并遮挡；教师点击单个「?」或「全部揭晓」。已知量不包 `<Answer>`。
11. **已知量可见**：需要课堂计算的场景，在数据面板放一行「已知 …」（如 λ · d · L），不要只放在侧栏滑杆上。
12. **慢放**：快速过程的场景传 `timeControl`，循环里把帧间隔乘以 `getPlaybackRate()`，播放面板出现「速度 1× / ½× / ¼×」。
13. **记号与量级**：屏幕文字用教材记号（`U<sub>AB</sub>`，不写 `U_AB`；不用 a.u.）。为可视化缩小的量级须标「示意」，并在备注中换算到教材量级。
14. **课堂连续性**：教师调好的参数按场景记住（`app/sceneMemory`：`useState(() => recall(...))` + `useRemember`，或 `rememberFields` / `useRememberFields`），切换场景或刷新后保留，新标签页恢复默认；侧栏末尾「恢复默认参数」清除。只记参数，不记运行状态与实验记录。
15. **单步有意义**：「单步」按课堂讨论的单位前进（转 15°、T/4、半圈、0.1 s 频闪间隔），并在播放面板提供，快捷键「.」。
16. **离线可用**：生产构建生成 `sw.js` 预缓存全部文件，打开一次后断网仍可使用（导航页显示「已缓存，断网也可使用」）。
17. **触控友好**：所有交互元素最小 44px 触控目标，符合 WCAG 2.5.5。

## 4. 新场景接入清单

1. 为 `SceneLayout` 传入 `controls`、`dataOverlay`、`playbackActions`，按需传入 `chart` / `chartVisible` 与 `notes`。
2. 保持分层结构：`useXxxSceneState` + `XxxControls` + `XxxRig3D` + `XxxScene` 壳层。
3. `dataOverlay` 只含 3~5 行结论量；参数回显与解释性文字放 `notes` / `<ModelNote>`。
4. 播放、步进、重置用 `playbackActions`；主播放动作的 `key` 用 `play` 或 `toggle-running`，以便空格键生效。
4a. 结论读数包 `<Answer>`；计算类场景加「已知」行；快速过程传 `timeControl` 并在循环中使用 `getPlaybackRate()`。
4b. 3D 线条从 `scene3d/ClassroomLine` 引入 `Line`（课堂大字时自动加粗）。
4b2. 新场景的图表优先用 `ui/charts/LineChart`，3D 矢量用 `scene3d/VectorArrow`（标签自动避开箭头）。
4c. 导航页有三种视图（按教材 / 按专题 / 按课型，记住上次选择）和搜索（快捷键 /）。新场景须在 `ui/navigation/regionData.ts` 的教材章节，以及 `ui/navigation/navigationViews.ts` 的专题与课型中各登记一次（组内按教学顺序；测试会检查每个视图恰好覆盖全部场景），并运行 `npm run thumbnails -- <pageId>` 生成缩略图。卡片编号与 1–9 快捷键跟随当前视图。
4d. 首页按需加载：导航页与快捷键帮助为懒加载，首页不预加载 three.js / R3F（`check:homepage-preload` 会拦截）；入口 JS 预算 35 kB。
5. 相机居中构图即可，交给安全区避让面板；如场景自行计算避让（如测量工具按读数区缩放），传 `screenOffset`，安全区会自动让位。
6. 默认状态应可直接讲解，不要求教师先点若干步骤。

## 5. 移动端适配（≤767px）

- header 隐藏标题，只显示 [返回] + [播放按钮] + [昼夜切换]
- viewport 占满剩余空间，不做安全区映射
- 底部面板固定 30vh，通过 SegmentedControl 切换 参数/数据/图表 tab；教师备注位于参数 tab 末尾
- 播放控制不再单独显示，已提升到 header
- 不提供讲解模式与课堂大字

## 6. 常见反模式（禁止）

- 把核心读数放在折叠面板深处且无其他区域可见替代。
- 让教师必须多次点击才能看到当前结论或开始播放。
- 新场景不提供 `dataOverlay`，或数据面板超过 5 行、重复侧栏参数。
- 为避让面板而按 `sidebarCollapsed` 或面板位置实时移动相机（会在教师操作面板时重置视角）。
- 在侧栏正文堆放大段模型说明。
- 浮层按钮使用小于 44px 的触控目标。
